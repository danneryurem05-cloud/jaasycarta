CARTA INTERACTIVA PARA JAASIEL

1. Abre esta carpeta en VS Code.
2. Abre index.html con Live Server (recomendado) o directamente en el navegador.
3. Si quieres cambiar el texto, edita solamente el arreglo "pages" dentro de script.js.
4. Para publicarlo en GitHub Pages, sube los 3 archivos al repositorio y activa Pages.

Archivos:
- index.html
- style.css
- script.js
